# 离线权重清单

在有网机器下载后，全部放到 `yolo-studio/weights/`，再随 Docker 镜像或 U 盘带进内网。

| 文件名 | 用途 | 大约体积 | 获取方式 |
|---|---|---|---|
| `yolo26n.pt` | 从零训练默认底模（CPU 首选） | ~5–6 MB | [Ultralytics Assets](https://github.com/ultralytics/assets/releases) 或有网时 `yolo predict model=yolo26n.pt source=bus.jpg` 触发缓存后，从 `~/.cache/ultralytics/` / 当前目录拷贝 |
| `yolo26s.pt` | 从零训练备选（CPU 慢约 3 倍） | ~20 MB | 同上 |
| `0517_yolo26n_wheelie_multi-rider.pt` | 冷启动预标注 + 微调底模（微） | ~5.4 MB | 从 `~/project/bczj-classifier/models/` 拷贝 |
| `0517_yolo26s_wheelie_multi-rider.pt` | 冷启动预标注 + 微调底模（小） | ~20 MB | 从 `~/project/bczj-classifier/models/` 拷贝 |
| `yolov8s-worldv2.pt` | 开放词表零样本预标注 | ~25–40 MB | Ultralytics YOLO-World 发布包；有网时 `yolo predict model=yolov8s-worldv2.pt` 缓存后拷贝；或从 multi-rider 项目 weights 拷贝（若本机有） |
| `mobile_sam.pt` | SAM 点选辅助（**禁止用原版 SAM**） | ~40 MB | [MobileSAM](https://github.com/ChaoningZhang/MobileSAM) 官方权重；或从 multi-rider weights 拷贝（若本机有） |

## 字体（离线训练日志/画图）

| 文件 | 用途 | 说明 |
|---|---|---|
| `Arial.ttf` | ultralytics 画图用字体 | **Docker 构建已自动处理**：把系统 `DejaVuSans.ttf` 复制为 `/root/.config/Ultralytics/Arial.ttf`，内网无需单独下载。本地开发若缺字体，可自行放置到 `~/.config/Ultralytics/Arial.ttf` |

## 推荐一键拷贝（本机已有 bczj-classifier 时）

```bash
cd ~/project/yolo-studio
mkdir -p weights
cp ../bczj-classifier/models/0517_yolo26*.pt weights/
# 若 multi-rider 有 world / sam（路径因机器而异，没有就跳过）：
# cp ../multi-rider/weights/yolov8s-worldv2.pt weights/ 2>/dev/null || true
# cp ../multi-rider/weights/mobile_sam.pt weights/ 2>/dev/null || true
```

## 注意

1. **代码里只用绝对路径加载**，不会 `YOLO('yolov8n.pt')` 触发联网下载。
2. `weights/` 默认不进 git（见 `.gitignore`）。
3. 模型仓库训练产物会复制到 `data/models/`，发布后**后台异步**导出 OpenVINO 目录 `data/models/<id>_openvino_model/`；导出失败仍可用 `.pt`。
4. 去重当前实现为 **aHash**（感知哈希简化版），不是 pHash；大图集请分批跑。
