# 离线权重清单

在有网机器下载后，全部放到 `yolo-studio/weights/`，再随 Docker 镜像或 U 盘带进内网。

| 文件名 | 用途 | 大约体积 | 获取方式 |
|---|---|---|---|
| `yolo26n.pt` | 从零训练默认底模（CPU 首选） | ~5–6 MB | Ultralytics 发布页 / `yolo export` 同源下载；有网时可用 `yolo predict model=yolo26n.pt` 触发缓存后拷贝 |
| `yolo26s.pt` | 从零训练备选（CPU 慢约 3 倍） | ~20 MB | 同上 |
| `0517_yolo26n_wheelie_multi-rider.pt` | 冷启动预标注 + 微调底模（微） | ~5.4 MB | 从 `~/project/bczj-classifier/models/` 拷贝 |
| `0517_yolo26s_wheelie_multi-rider.pt` | 冷启动预标注 + 微调底模（小） | ~20 MB | 从 `~/project/bczj-classifier/models/` 拷贝 |
| `yolov8s-worldv2.pt` | 开放词表零样本预标注 | ~25–40 MB | 从 multi-rider 项目 weights 或 Ultralytics YOLO-World 发布包 |
| `mobile_sam.pt` | SAM 点选辅助（**禁止用原版 SAM**） | ~40 MB | MobileSAM 官方权重；有则从 multi-rider 拷贝 |

## 推荐一键拷贝（本机已有 bczj-classifier 时）

```bash
cd ~/project/yolo-studio
mkdir -p weights
cp ../bczj-classifier/models/0517_yolo26*.pt weights/
# 若 multi-rider 有 world / sam：
# cp ../multi-rider/weights/yolov8s-worldv2.pt weights/ 2>/dev/null || true
# cp ../multi-rider/weights/mobile_sam.pt weights/ 2>/dev/null || true
```

## 注意

1. **代码里只用绝对路径加载**，不会 `YOLO('yolov8n.pt')` 触发联网下载。
2. `weights/` 默认不进 git（见 `.gitignore`）。
3. 模型仓库训练产物会复制到 `data/models/`，并尽量自动导出 OpenVINO 目录 `data/models/<id>_openvino_model/`。
